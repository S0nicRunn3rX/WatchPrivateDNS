# История изменений Wear Private DNS

## 1.3.0 — 2026-10-06

- Приложение переименовано из Watch Private DNS в Wear Private DNS.
- Добавлена постоянная release-подпись APK вместо debug-подписи.
- APK публикуется как `WearPrivateDNS-v1.3.0.apk` без суффикса `debug`.

## 1.2.2 — 2026-10-05

- Добавлена новая иконка приложения.
- Обновлено оформление репозитория и документация.
- Закреплена поддержка системной светлой/тёмной темы и динамической палитры Wear OS.
- При подключении к интернету через телефон Private DNS временно переводится в режим «Отключён».
- Добавлено удаление DNS-адресов из истории долгим нажатием.

## 1.2.1

- Тема приложения теперь следует системному режиму и Material You.

## 1.2.0

- Добавлена фоновая политика Private DNS с обработкой Bluetooth sysproxy.
- Добавлена проверка активации strict Private DNS и история hostname.
